# Start Guide

## First 5 Minutes

1. Log in at `/login`.
2. Open `/command`.
3. Add today's Daily Log: sleep, energy, stress, study minutes and passive/active split.
4. Create the first subject, exam and 3-5 topics.
5. Add one review item and one error log if there is already a known weak point.

## Daily Flow Under 60 Seconds

1. Open `/command`.
2. Fill or update the Daily Log.
3. Read the Next Best Action.
4. Start the suggested page: reviews, errors, topic, exam, language, opportunity or recovery.
5. At the end of a session, log method, focus, energy and output quality.

## Weekly Flow

1. Review `/elite-index`.
2. Open `/errors` and resolve/retest the highest severity recurring errors.
3. Open `/reviews` and clear overdue items.
4. Open `/time` and check planned vs actual execution.
5. Open `/strategic-review` and write one weekly review: wins, weaknesses, decisions and next focus.

## Exam Build-Up

1. Open the exam command center from `/exams`.
2. Check readiness breakdown, weak topics, errors, quiz attempts and sessions.
3. Use simulation when the exam is near and readiness is below 6/10.
4. Use error review when severe errors are still open.
5. Use light review or recovery if burnout risk is high.

## Tartu Layer

Use `/tartu`, `/language`, `/life-admin` and `/opportunities` to keep the Estonia transition practical. Track language practice, documents, academic culture notes and strategic opportunities.

## Identity Layer

Use `/identity`, `/reputation`, `/network` and `/portfolio` to build a quiet professional identity: high standards, boundaries, reliable work, precise questions and evidence of progress.
